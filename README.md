# EQAO Worksheet Generator 📚

Professional worksheet generator for Ontario EQAO mathematics assessments (Grades 3, 6, and 9).

## ✨ Features

- ✅ Ontario curriculum-aligned questions for Grades 3, 6, and 9
- ✅ Full-length practice tests or custom strand-focused worksheets
- ✅ Auto-generated diagrams: arrays, graphs, geometry, fractions, coordinate planes
- ✅ Print-ready layout with proper page breaks
- ✅ Answer keys and Ontario Achievement Chart rubrics
- ✅ Accessible design (ARIA labels, keyboard navigation)
- ✅ Responsive for desktop and mobile

## 🚀 Quick Start

1. Download `index.html`
2. Open in any modern browser (Chrome, Firefox, Edge, Safari)
3. Configure your worksheet settings
4. Click **Generate Worksheet**
5. Print or save as PDF

## 🖨️ Printing / PDF Export

1. Click **Print Worksheet** or **Download PDF**
2. In the print dialog, select **"Save as PDF"** as your printer
3. Adjust margins to "None" or "Minimum" for best results
4. Click Save

## 🛠️ Customization

- **Add questions**: Edit the `questionBanks` object in the JavaScript section
- **Add strands**: Update `mathStrands` configuration
- **Modify styling**: Edit CSS variables in the `<style>` section

## ♿ Accessibility

- Full keyboard navigation support (`Ctrl+Enter` to generate)
- ARIA labels on all interactive elements
- Screen reader-friendly diagram descriptions
- High-contrast print mode
